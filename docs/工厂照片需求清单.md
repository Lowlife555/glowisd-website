# 工厂照片需求清单（发给供应商 / 自己拍都可以）

> 用途：Glowisd 官网「工厂介绍」页与首页工厂区块共 **7 个图片槽位**，现在全是占位图。
> 把这份清单直接转发给工厂对接人，或按它自己拍，都能用。
> 拿到照片后放到一个文件夹，一条命令就能整理成可上传的规格（见文末）。

## 一、要哪 7 张（按槽位，文件名就用左边的英文名）

| 槽位 key | 拍什么 | 用在哪 |
|---|---|---|
| `factory_hero` | 厂房**外景**：正门/大门前，能看出是厂区，最好带公司招牌 | 工厂页顶部大图 |
| `workshop_1` | **组装产线**：工人在工位装配（传感器/线缆/手柄类电子件最好） | 工厂页「车间一瞥」01 |
| `workshop_2` | **CNC 加工区**：机床在加工，能看到刀库/工装夹具 | 工厂页 02 |
| `workshop_3` | **检测/标定区**：有人在做检测、测台、仪器屏幕可见 | 工厂页 03 |
| `workshop_4` | **成品仓储**：货架/打包区/待发货物 | 工厂页 04 |
| `home_factory` | 车间**全景**（比 workshop 更宽、更亮，能看出场地规模） | 首页「工厂」区块 |
| `custom_hero` | 能体现**定制/OEM** 的场景：打样台、图纸与零件同框、包装线 | 定制服务页 |

## 二、拍摄/挑选要求

- **横图**，比例接近 **4:3**（手机横着拍就行；我们会统一裁成 1600×1200）
- 分辨率不低于 **1600×1200**，单张原图 ≤ 8MB
- **干净**：不要拍到别家品牌 logo、客户图纸、白板上的报价、人员工牌
- **有人**比空厂房可信（不用正脸特写，侧影/背影即可），但要先确认当事人同意
- 光线尽量亮，别用美颜/强滤镜；不要加文字贴纸和水印
- 每张最好能一句话说明"这是哪个工位在做什么"

## 三、授权（重要）

照片必须是**我们有权使用**的。以下三种任一即可：

1. 自己拍的（含工厂现场拍的）——最省事
2. 供应商提供，并在微信/邮件里写明「同意用于 Glowisd 官网展示」
3. 付费图库购买（保留授权凭证）

⚠️ 不要从同行官网、1688/阿里巴巴、朋友圈或百度图片直接下载：
那些图是**别的公司的财产**，多数带他们的水印，被反查图片找到会同时踩版权和虚假宣传两条线。

## 四、拿到照片后怎么装

把 7 张按上表命名（如 `factory_hero.jpg`、`workshop_1.jpg`），放进一个文件夹，然后：

```bash
# 1) 统一规格（裁 4:3、1600×1200、压到 400KB 内、去掉 EXIF/GPS）
venv/bin/python scripts/install_factory_photos.py prepare --src ../工厂照片 --out ../工厂照片-ready

# 2) 打开后台「站点图片」，把 ready 目录里 7 个文件分别拖进同名槽位，填一句说明即可
#    （工厂页「车间一瞥」在传了任意一张 workshop 后会自动出现，不用改代码）
```

命名不是槽位 key 的文件会被跳过并提示，重复的取第一个。
