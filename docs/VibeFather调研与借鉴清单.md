# VibeFather 调研报告与 Glowisd 可借鉴清单

> 调研对象：https://vibefather.ai/zh （B 站 UP 主做的「vibe coding 网站模板 + AI 提示词」站）
> 调研时间：2026-11-21 · 调研范围：首页、定价页、标签页、3 个最相关模板详情页 + 3 个在线演示实拍
> 结论用途：判断「免费前提下能拿什么、能怎么用」

---

## 结论先行（TL;DR）

1. **免费能看的东西确实多**：603 个在线演示全部公开可浏览、所有 `DESIGN.md` 设计规范全文公开、免费模板的完整提示词也全文公开。
2. **但免费部分的授权是 CC BY-NC 4.0 = 禁止商用**。glowisd.cn 是公司商业官网，所以 —— 提示词原文、`DESIGN.md`、演示源码，**都不能直接搬进项目**。
3. **可以合法借鉴的是「结构与机制」**（信息架构、模块顺序、交互套路、字段设计）。这类抽象想法不受版权保护，照着重写不算侵权。**要照抄的是骨架，不是代码和文案。**
4. **演示里的内容全是编的**，页面自己写着 "machines, parts, clients and prices invented"、"sample claim for this demo"。所以数字、设备清单、客户案例都不能抄 —— **这些恰好是 Glowisd 最缺、也最必须由你提供的**。
5. **Glowisd 现有的底子不差**：产品页已有规格表（`dl.meta-table`：SKU/兼容品牌/重量/质保）、询价 CTA（带 product+category 参数）、工厂页六步流程图、三语文案、`base.html` 里有 JSON-LD。
6. **真正缺 4 块**：①设备明细表 ②交期/参考价估算器 ③FAQ（含 FAQPage 结构化数据）④真实案例卡。
7. **这 4 块全部需要你的真实参数**才能上（设备台数型号、交期区间、起订量、付款条款、真实项目）。给我数据，我就能建；没有数据硬做，就是假数据，客户一问就穿。

## 一、这个站到底是什么

不是内容站，是**卖「网站模板 + 可复制的 AI 提示词」的工具站**：

- 每个模板 = 一份写给 AI 编程工具的完整提示词（技术栈、布局、配色、字体、文案、动效全写死）+ 一个用同一份提示词做出来的在线演示
- 用法：打开模板 → 复制提示词 → 把 `[BRAND]` `[CITY]` 等变量换成自己的 → 粘进 Claude Code / Cursor / Codex / Trae 等
- 还提供 `DESIGN.md`（只描述视觉规范，可以单独拿去改造已有项目）和 CLI（`npx vibefather add <slug>`，把 `prompt.md` + `DESIGN.md` 放进项目）

规模：**603 个在线演示**、**77 个 Pro 模板**，覆盖落地页 / SaaS / 作品集 / 电商 / 3D / 小游戏 / 行业站（含工业制造、机器人、物流货运、建筑承包、暖通、律所、诊所等）。

## 三、授权：为什么「免费」不等于「你能用」

免费部分的授权是 **CC BY-NC 4.0**，模板页提示词末尾原文写着：

> — Prompt by VibeFather · CC BY-NC 4.0 (non-commercial; commercial use needs a VibeFather Pro license)

`NC` = NonCommercial = **禁止商业使用**。glowisd.cn 是常州工厂对外获客的商业官网，属于典型商业用途。

### 可以做（不需要授权）

- 看演示、读 `DESIGN.md`，**提炼出结构与做法**（比如「规格表用等宽数字」「询价前先给交期区间」）
- 用**自己的代码和自己的文案**重新实现同样的机制
- 学它的信息架构、字段设计、页面顺序、转化路径

### 不可以做

- 把提示词 / `DESIGN.md` / 演示源码**复制进 Glowisd 项目**（哪怕改了品牌名）
- 把演示的**文案、配色方案原样挪用**（配色/字体列表属于它的设计作品表达）
- 用它演示里的**编造数据**（设备型号、间隔公差、客户案例）当自己的宣传素材

### 想要模板级产物怎么办

- 买 Pro（¥64 起）→ 拿到商用授权 + 源码，可以直接改
- 但**我的建议是先不买**：见第五节，Glowisd 缺的不是模板，是真实数据

### 1）工业制造公司网站（Pro 模板，演示公开可看）

Demo：`demo.vibefather.ai/16080d09-ae32-4fdc-846e-ad95636eb935/index.html`
截图：`docs/screenshots-vibefather/im-01 ~ im-04`

逐段结构：

| 段落 | 做法 | 值得学的点 |
|---|---|---|
| 首屏 | 深色车间实景大图 + 一句话狠话 "TOLERANCES OTHERS DECLINE." + 两个按钮（Send an RFQ / Estimate lead time）+ 三枚信任筹码（±0.0005 in milling · ISO-style documented QMS · 2 shifts, Mon–Fri） | **口号讲客户的痛，不讲自己多强**；首屏就给两条路径：直接询价 / 先估算 |
| 能力区 | 4 张卡：CNC 铣 / 车 / 钣金焊接 / 表面处理，每卡 = 一句公差规格 + 可加工材料 chips + 「Quote this process →」 | **能力按条目拆开，每条都能直接变成询价入口** |
| 设备表 | 6 行表：MACHINE / TRAVEL / SPINDLE·SOURCE / TOLERANCE / NOTE，等宽数字，表格无竖线 | **B2B 买家真的会看设备表**；一行一条产线，规格式呈现 |
| 行业 + 质检 | 4 张行业卡（能源电网 / 食品设备…）+ 右侧质量清单 5 条打勾（CMM 检测、首件检验、材料证书、QMS、双班巡检） | 用「可核实的具体动作」替代「品质保证」四个字 |
| 估算器 | 选 工序 / 材料 / 表面处理 / 数量 → 右侧输出「16 工作日」「$17–$22/件」+ **推算过程逐条列出**（基础 3 天 + 数量档 +9 天 + 阳极氧化 +4 天）+ 免责声明 + 「Open the RFQ form →」 | **把计算过程摊开给人看**，比一个孤零零的数字可信得多；结尾顺势推进表单 |
| 询价表单 | Name / Company / Email / Phone / Material / Finish / 上传图纸 + Send RFQ | 字段按「报价必需信息」组织，不是通用联系表单 |
| 招聘 + 页脚 | 三个岗位卡 + 联系方式 | 制造业官网加招聘区，成本低、显真实 |

## 六、建议采纳的 4 个模块（按 ROI 排序）

### ① 交期 / 参考价估算器（询价页或产品详情页）

- **做什么**：选「配件类别 → 数量档 → 是否定制线束/加急」→ 输出「预计 X–Y 个工作日」+「参考价区间」+ 逐条推算依据 + 免责声明 + 「按这个需求询价」按钮（自动带参进 `ContactMessage`）
- **为什么值**：B2B 客户第一句永远问「多少钱、多久能到」。把这两个问题在询价前先答个区间，转化率提升最直接；且推算过程摊开 = 可信
- **要你的数据**：每个类别的**参考单价区间**、**数量折扣档**、**常规交期/加急交期**、**定制项加价系数**
- **工作量**：1 个页面模块 + 1 段 JS + 1 个配置表，约半天

### ② 设备明细表（工厂页）

- **做什么**：6–8 行表格：设备名 / 数量 / 用途 / 关键能力（等宽数字右对齐，无竖线）
- **为什么值**：「SMT 贴片、线束组装、标定产线」这些话你文案里写了，但**没有设备表就等于自说自话**。B2B 买家、尤其欧洲/中东代理商会截图给技术方看
- **要你的数据**：设备清单（贴片机/回流焊/波峰焊/压接机/CNC/标定台/老化架…的型号、数量、能力参数）
- **工作量**：1 个表格区块 + CSS，约 2 小时

### ③ FAQ + FAQPage 结构化数据

- **做什么**：8–10 条问答，覆盖：起订量 MOQ、常规交期、付款方式（T/T、L/C？）、运费与贸易条款（FOB/CIF？）、质保期限与索赔流程、是否支持 OEM/ODM、能否提供测试报告、发货到中东/欧洲通常多久
- **为什么值**：这类长尾问题正是海外买家在 Google 搜的；配 `FAQPage` schema 有机会出富摘要，成本最低的 SEO 动作
- **要你的数据**：上面每条的真实政策（**不能编，编了会引来纠纷**）
- **工作量**：1 个 FAQ 区块 + JSON-LD，约 3 小时

### ④ 案例卡（3 个真实项目）

- **做什么**：3 张卡：客户类型（可脱敏为「中东某道路施工承包商」）+ 遇到什么问题 + 我们供了什么 + 结果（停机时间/交期/复购）
- **为什么值**：比任何参数表都更能说服人
- **要你的数据**：3 个真实交付故事（可脱敏）
- **工作量**：1 个区块，约 3 小时（内容比代码难）

## 八、不建议做的事（也写下来，免得后面反复讨论）

1. **不要抄 `DESIGN.md` / 提示词 / 源码** —— CC BY-NC，商用违规，而且是别人花钱维护的资产
2. **不要照搬 3D / WebGL / 电影感滚动** —— 那些模板是给硬件发布会、腕表、音乐节做的，跟「摊铺机配件」的买家（工地技术人员、采购、代理商）不匹配；而且会让页面变重、移动端变慢，中东/欧洲的 4G 现场打开更慢
3. **不要用 AI 编设备参数和客户案例** —— 样板自己都标了 "every number invented"，那是演示，不是可抄的内容。印到官网上，客户一个技术问题就穿帮
4. **不要为了「像模板」而加功能** —— 现有的六步流程、三语、产品规格表已经比多数样板更细
